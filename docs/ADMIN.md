# Документація адміністратора — Мисливські Сигнали

## Вхід в адмін-панель

1. Відкрийте додаток
2. На головному екрані натисніть кнопку **«Адмін»** (зазвичай у правому верхньому куті або в меню)
3. Введіть пароль: **`1488`**
4. Натисніть **«Увійти»**

> **Увага:** Пароль зберігається у вихідному коді (`lib/services/admin_service.dart`). Для продакшн-версії рекомендується замінити на безпечну автентифікацію.

---

## Управління сигналами

### Додавання нового сигналу

1. В адмін-панелі натисніть **«Додати сигнал»**
2. Заповніть форму:

| Поле | Опис | Обов'язкове |
|---|---|---|
| Назва | Назва сигналу | Так |
| Опис | Короткий опис | Так |
| Категорія | Категорія з наявних | Так |
| Тривалість (сек) | Тривалість сигналу в секундах | Так |
| Аудіо URL | Посилання на аудіофайл | Ні |
| Відео URL | Посилання на відео | Ні |
| URL нотації | Посилання на зображення нотації | Ні |
| Текст сигналу | Словесний опис / слова сигналу | Ні |
| Темп нотації | BPM для графічних нот | Ні |
| Складність | `beginner` / `intermediate` / `advanced` | Ні |
| Теги | Теги через кому | Ні |

3. Натисніть **«Зберегти»**

### Редагування сигналу

1. Знайдіть сигнал у списку
2. Натисніть кнопку редагування (олівець)
3. Змініть потрібні поля
4. Збережіть зміни

### Видалення сигналу

1. Знайдіть сигнал у списку
2. Натисніть кнопку видалення (кошик)
3. Підтвердіть видалення

> **Увага:** Видалення є незворотним. Сигнал видаляється з Firebase Firestore.

## Медіафайли — правила підготовки

### Аудіо (Google Drive)

1. Завантажте MP3/WAV файл на Google Drive
2. Відкрийте доступ: **«Усі, хто має посилання»** → **«Переглядач»**
3. Скопіюйте посилання виду: `https://drive.google.com/file/d/XXXXXX/view?usp=sharing`
4. Вставте це посилання у поле **Аудіо URL**

> Додаток автоматично конвертує посилання у формат для завантаження.

### Відео

**Варіант А — YouTube:**
- Скопіюйте звичайне посилання на відео: `https://www.youtube.com/watch?v=XXXXX`
- Або скорочене: `https://youtu.be/XXXXX`
- Вставте у поле **Відео URL**

**Варіант Б — Google Drive:**
- Аналогічно до аудіо: відкрийте доступ → скопіюйте посилання

### Зображення нотацій

1. Підготуйте зображення PNG/JPG (рекомендована ширина: 1200+ px)
2. Завантажте на Google Drive, відкрийте публічний доступ
3. Скопіюйте посилання → вставте у поле **URL нотації**

### Обкладинки відео (навчальний модуль)

- **YouTube:** обкладинка підбирається автоматично, вводити нічого не потрібно
- **Google Drive:** завантажте зображення-обкладинку на Drive, відкрийте публічний доступ, вставте посилання у поле **Thumbnail URL**

## Управління навчальним контентом

Навчальний модуль структурований як: **Тема → Матеріали**

### Кроки для налаштування навчання:

1. В адмін-панелі перейдіть до розділу **«Навчання»**
2. Спочатку створіть **теми** (розділи курсу)
3. Потім для кожної теми додайте **матеріали**
4. За бажанням додайте **флеш-картки** та **питання тесту**

---

### Додавання теми

1. Натисніть **«Додати тему»**
2. Введіть:
   - **Назва теми** — відображається у списку
   - **Опис** — підзаголовок теми
   - **URL зображення** *(необов'язково)* — обкладинка теми

---

### Додавання навчального матеріалу

1. Виберіть тему → натисніть **«Додати матеріал»**
2. Виберіть **тип матеріалу**:

| Тип | Вкладка | Призначення |
|---|---|---|
| Мультимедійний | «Мультимедійні» | Відео, фото, презентації, документи |
| Лекційний | «Лекційні» | Текстові лекції, PDF |
| Практичний | «Практичні» | Практичні завдання |

3. Для **мультимедійного** типу виберіть підтип:

| Підтип | Підтримувані формати |
|---|---|
| Відео | YouTube URL, Google Drive відеофайл |
| Фото | Google Drive зображення |
| Презентація | Google Slides URL, `.ppt`/`.pptx` |
| Документ | Google Docs, Google Sheets, `.pdf`, `.doc`, `.xlsx` |

4. Введіть:
   - **Назва** — відображається у картці матеріалу
   - **URL** — посилання на файл (Google Drive або YouTube)
   - **URL обкладинки** *(тільки для відео)* — якщо залишити порожнім, для YouTube підбирається автоматично

---

### Додавання флеш-карток

1. Виберіть тему → перейдіть до розділу **«Флеш-картки»**
2. Натисніть **«Додати картку»**
3. Введіть **питання** та **відповідь**
4. Збережіть

Флеш-картки відображаються у режимі перегортання — корисні для запам'ятовування.

---

### Додавання тестових питань

1. Виберіть тему → розділ **«Тест»**
2. Натисніть **«Додати питання»**
3. Введіть:
   - **Питання**
   - **4 варіанти відповіді**
   - **Правильний варіант** (номер від 0 до 3)
   - **Пояснення** *(необов'язково)* — показується після відповіді

## Підготовка графічних нот (notationData)

Графічні ноти — інтерактивне відображення з мигаючим курсором і BPM-метрономом.

### Формат JSON

```json
[
  {"pitch": "C4", "duration": 1.0},
  {"pitch": "D4", "duration": 0.5},
  {"pitch": "E4", "duration": 0.5},
  {"pitch": "rest", "duration": 1.0}
]
```

| Поле | Значення |
|---|---|
| `pitch` | Нота (C4, D4, E4, F4, G4, A4, B4, C5 ...) або `"rest"` для паузи |
| `duration` | Тривалість у частках такту (1.0 = ціла, 0.5 = половина, 0.25 = чверть) |

### Рекомендований темп (notationTempo)

| Характер сигналу | BPM |
|---|---|
| Повільний | 60–80 |
| Помірний | 80–100 |
| Жвавий | 100–120 |
| Швидкий | 120–160 |

## Поширені проблеми

### Аудіо не відтворюється

1. Перевірте, що файл на Google Drive має публічний доступ («Усі, хто має посилання»)
2. Перевірте формат URL: має містити `/file/d/` або `?id=`
3. Файл має бути у форматі MP3 або WAV

### Відео не відкривається

1. Для YouTube: перевірте, що відео не є «приватним»
2. Для Google Drive: перевірте публічний доступ до файлу

### Обкладинка не відображається

1. Для YouTube — обкладинка підбирається автоматично, нічого робити не потрібно
2. Для Google Drive: переконайтесь що посилання на зображення відкрите публічно, і сам URL є прямим посиланням на файл (не папку)

### Матеріал не з'являється у списку

- Дані зберігаються у Firebase і завантажуються при відкритті екрану
- Перезавантажте екран (поверніться назад і відкрийте знову)
- Перевірте підключення до інтернету
